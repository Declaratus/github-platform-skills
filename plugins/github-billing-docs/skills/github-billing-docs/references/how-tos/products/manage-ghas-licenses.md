There are two different ways to pay for GitHub Secret Protection, GitHub Code Security, and GitHub Advanced Security licenses: volume/subscription licenses purchased in advance or usage-based metered billing paid in arrears. This article is about volume/subscription licenses. For information about the two different billing models, see [AUTOTITLE](/billing/concepts/product-billing/github-advanced-security).

For information about using policies to control use of licenses in your enterprise, see [AUTOTITLE](/admin/enforcing-policies/enforcing-policies-for-your-enterprise/enforcing-policies-for-code-security-and-analysis-for-your-enterprise).

## Changing the size of your license

1. Navigate to your organization or enterprise. For example, from the [Organizations](https://github.com/settings/organizations?ref_product=github&ref_type=engagement&ref_style=text) or [Enterprises](https://github.com/settings/enterprises?ref_product=ghec&ref_type=engagement&ref_style=text) pages on GitHub.com.
1. From the list of "Billing & licensing" pages, click **Licensing**.

   ![Screenshot of the Advanced Security licensing screen. The "Manage licenses" button is outlined in orange.](/assets/images/help/enterprises/ghas-licenses-dropdown.png)

1. To add new licenses, select (icon: kebab-horizontal), then click **Manage licenses**.
1. Under "Total licenses", click the plus or minus buttons to add or remove licenses.

   ![Screenshot of the Advanced Security license screen. A text box with the number 5, with a minus and a plus button, are outlined in orange.](/assets/images/help/enterprises/ghas-add-licenses.png)

1. Click **Confirm licenses**.

## Canceling your Advanced Security subscription

1. Navigate to your organization or enterprise. For example, from the [Organizations](https://github.com/settings/organizations?ref_product=github&ref_type=engagement&ref_style=text) or [Enterprises](https://github.com/settings/enterprises?ref_product=ghec&ref_type=engagement&ref_style=text) pages on GitHub.com.
1. From the list of "Billing & licensing" pages, click **Licensing**.
1. To the right of "Advanced Security", select (icon: kebab-horizontal), then click **Cancel subscription**.
1. To confirm your cancellation, click **I understand, cancel Advanced Security**.

## Disabling GitHub Advanced Security in an enterprise

Enterprise owners can disable GitHub Advanced Security completely and set a policy to prevent future re-enablement. See [AUTOTITLE](/billing/how-tos/products/disable-ghas-for-enterprise).
