# Projects and Issues changes newer than the docs snapshot

github/docs does not carry the GitHub Changelog. The bundled `references/` tree is a snapshot (see `references/SOURCE.json` for the upstream commit date), and features often ship, change status or get renamed before the docs catch up.

Before answering anything about feature availability, preview vs GA status, or recently added fields, views and relationships, check the label feed for entries newer than the snapshot:

https://github.blog/changelog/label/projects-and-issues/feed/

Older entries are on `?paged=2`, `?paged=3` and so on. Where the feed and the docs disagree, the newer dated source wins, and say which one you used.
