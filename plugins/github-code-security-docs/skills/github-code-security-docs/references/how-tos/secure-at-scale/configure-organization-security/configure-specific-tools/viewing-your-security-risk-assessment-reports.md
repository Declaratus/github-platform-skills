1. On GitHub, navigate to the main page of the organization.
1. Under your organization name, click the **(icon: shield) {% ifversion security-and-quality-tab %}Security and quality{% else %}Security{% endif %}** tab.
1. In the sidebar, under "Security", click **(icon: key) Assessments**. You can see the most recent report on this page.
1. Click the **Code Security** or **Secret Protection** tab to switch between reports.
