1. In the upper-right corner of any page on GitHub, click your profile picture, then click **(icon: gear) Settings**.
1. In the "Security" section of the sidebar, click **(icon: codescan) Code security**.
1. Under "User", to the right of "Push protection for yourself", update your settings.
